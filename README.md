# Image Feature Analysis

画像分類AIが画像のどのような特徴を利用して判断しているのかを分析するためのツール群です. 

本リポジトリでは, 画像から得られる低レベルな画像特徴量から, CNNやVision Transformer（ViT）などの深層学習モデルが内部で形成する特徴表現までを対象として, 特徴量の抽出・可視化・定量評価・寄与分析を行います. 

## 概要

画像分類モデルは, 単純に「画像全体」を見て判断しているわけではありません. 

色, 明度, エッジ, テクスチャ, 形状などの視覚的特徴や, ニューラルネットワーク内部で形成されたより抽象的な特徴表現を組み合わせて予測を行っています. 

本リポジトリでは, こうした特徴を可能な限り分解して調べることで, 

- 画像分類モデルがどのような特徴を利用しているのか
- どの画像領域が予測に寄与しているのか
- 特徴量と分類結果にどのような関係があるのか
- 異なるモデルがどのような特徴を利用しているのか

を定量的・視覚的に分析することを目的とします. 

## 主な機能

### 1. 画像特徴量の抽出

画像から以下のような基本的な特徴量を抽出します. 

- 平均輝度
- 色相
- 彩度
- RGB各チャンネルの統計量
- エッジ量
- その他の画像統計量

これらの特徴量をCSVなどの形式で保存し, 後から統計解析や機械学習に利用できます. 

### 2. Deep Feature Extraction

CNNやVision Transformer（ViT）などの画像認識モデルから特徴表現を抽出します. 

想定するモデル例：

- ResNet
- EfficientNet
- Vision Transformer
- その他のPyTorch / torchvision対応モデル

モデルの最終的な分類結果だけではなく, 中間層などから特徴表現を取得することで, モデル内部で形成される視覚表現を分析します. 

### 3. Feature Visualization

抽出した特徴量を可視化し, 画像分類結果との関係を調べます. 

例えば, 

- 特徴量分布
- クラス間の特徴量比較
- 特徴量の相関
- 特徴量による画像群の分布
- 特徴量と予測結果の関係

などを可視化します. 

### 4. Occlusion-based Analysis

画像の一部分を隠し, その際に分類結果がどの程度変化するかを調べることで, モデルの判断に寄与している画像領域を推定します. 

基本的な考え方は, 

1. 元画像をモデルに入力する
2. 画像の一部分を遮蔽する
3. 遮蔽後の予測結果を取得する
4. 元画像との予測差を計算する
5. 遮蔽位置を移動して繰り返す

というものです. 

これにより, 画像上のどの領域が分類結果に重要であったかをヒートマップとして表現できます. 

### 5. Adaptive Feature Occlusion

固定サイズの領域を一律に遮蔽するだけではなく, 画像領域を再帰的に分割しながら重要な領域を探索する手法を実装しています. 

これにより, 

- 大まかな重要領域
- 局所的な重要領域
- モデルが強く反応する領域

を異なる空間スケールで分析できます. 

モデルに依存しない解析手法として利用することを目指しています. 

## 対応予定モデル

現在はPyTorch / torchvisionを中心として, 以下のようなモデルを対象としています. 

- ResNet18
- ResNet50
- EfficientNet-B0
- ViT-B/16
- その他の画像分類モデル

今後, YOLOなどの物体検出モデルへの対応も予定しています. 

## 出力

解析結果は, 用途に応じて以下の形式で保存します. 

- CSV
- JSON
- PNGなどの画像
- ヒートマップ
- 領域情報
